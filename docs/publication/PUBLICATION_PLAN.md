## 2. Mathematical note

Working title: **An exact rational witness for the minimum-autocorrelation functional**.

Lead with the exact inequality and finite witness, then explain the piecewise-affine reduction, independent arithmetic checks, corrupted-certificate controls and comparison with the attributed baseline. Describe the search as computer-assisted with native agent choices and operator-supplied algorithms. Do not use “Millennium solution,” “global optimum,” or “guaranteed world record.”

The compact package can be reviewed now. Before submitting a full research deposit, add an externally reviewed mathematical note, a broader documented priority search, and a curated complete search lineage with code/configuration versions and actor attribution. Obtain an actual DOI from the deposit service only after creating the deposit; never reserve a fictional identifier in metadata.

## 3. Engineering evaluation

Working title: **Failure-aware scientific tool use with retained execution evidence**.

Report all four model-calibration batches, including the failed parser revision. Separate operational completion, quantitative correctness and provenance integrity. Use the same held-out tasks and repeated seeds across configurations before making model or performance superiority claims. A successful short run is not evidence of reliability over days.

## 4. Supporting data

Keep local Singer exclusions, unit-distance searches, SSH diagnostics and Lean replays as explicitly scoped supporting material. They can be useful reproducibility assets without constituting new scientific discoveries. Do not submit them as separate breakthrough papers on the present evidence.
