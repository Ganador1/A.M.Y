# What the provenance establishes

| Layer | Available evidence | What it does not establish |
|---|---|---|
| Recorded bytes | SHA-256 artifacts and chained events | Authenticity against an attacker who can rewrite all roots |
| Execution context | Retained configuration, source identities, inputs and outputs | Coverage of uninstrumented code or provider internals |
| Agent attribution | Native decision, action and receipt events | Invention of operator-supplied algorithms |
| Numerical consistency | H₂ and other scoped numerical checks | Exact physical truth or independent integral generation |
| Exact certificates | Rational or finite mathematical recomputation | Global optimality, novelty or priority |
| Build attestation | Workflow integration exists | An attestation for this unpublished local candidate |
| Trusted timestamps / signatures | Infrastructure and verifier code exist | A complete externally authenticated chain for every historical run |

The latest calibration audit checked 20 execution chains and 18 existing experiment journals. Two sessions performed no experiments and had no journal. Frozen files were unchanged within each campaign. These checks do not retroactively certify all historical AMY runs.

## Release chain

A reviewable release needs an exact source revision, dependency/build recipe, artifact hashes, validation results, release notes and the maintainer's approval. A CI build can attach its own provenance attestation to the bytes it actually builds. Do not label a local manifest as a provider signature or a completed SLSA assessment.

A scientific deposit additionally needs the witness or dataset, a checker, negative controls, a precise claim, source attribution, and the scope of reproduction. The compact autocorrelation package checks mathematical existence; the complete search trajectory is a separate archival deliverable and is not included in that compact package.

Translations and editorial corrections are separate artifacts. Raw prompts, transcripts and historical manifests must keep their original bytes. Before public archival, review transcripts for credentials, personal paths, licensing and redistribution rights; keep any redaction map separate from the mathematical witness.
