# Services in the Biology Domain

This document details all services available in the Biology domain, including descriptions, key features, and usage.

<a id="computationalbiologyservice"></a>
## ComputationalBiologyService
- **Description:** Handles simulations in neuroscience, genomics, and ecology.
- **Key features:** Neural simulations, network analysis, ecological modeling.
- **Usage:** Integrated into routers for simulation endpoints.

<a id="biomedicalnlpservice"></a>
## BiomedicalNLPService
- **Description:** NLP processing for biomedical texts.
- **Key features:** Entity extraction, semantic similarity, abstract analysis.
- **Usage:** Accessible via /biomedical-nlp endpoints.

<a id="biogptservice"></a>
## BioGPTService
- **Description:** Text generation with BioGPT.
- **Key features:** Hypotheses, summaries, explanations.
- **Usage:** Endpoints at /biogpt.

<a id="advancedgenomicsservice"></a>
## AdvancedGenomicsService
- **Description:** Advanced genomic analysis.
- **Key features:** Variants, cancer, pharmacogenomics.
- **Usage:** Endpoints at /advanced-genomics.

<a id="genomicsservice"></a>
## GenomicsService
- **Description:** Secure basic genomic analysis.
- **Key features:** Sequences, dry-runs.
- **Usage:** Endpoints at /genomics.

<a id="dnabert2service"></a>
## DNABERT2Service
- **Description:** DNA analysis with DNABERT2.
- **Key features:** Functional predictions.
- **Usage:** Endpoints at /dnabert2.

<a id="protgpt2service"></a>
## ProtGPT2Service
- **Description:** Protein generation with ProtGPT2.
- **Key features:** Sequence design.
- **Usage:** Endpoints at /protgpt2.

For more details, consult the source code in services/.
