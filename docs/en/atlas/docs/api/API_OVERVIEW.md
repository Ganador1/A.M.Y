# API Overview (Executive)

This page centralizes the main endpoints. For exhaustive details use the autogenerated FastAPI documentation (`/docs`) or the individual routers.

<a id="categorías-clave"></a>
## Key Categories

- Fundamental Mathematics (calculus, algebra, number theory, transforms)
- Physics and Simulation (PDE, crystallography, computational chemistry, basic quantum)
- Data Science and ML (time series, plausibility, experiment scheduler)
- Autonomous Laboratory (workflow orchestration, reproducibility, integrity, sandbox)

<a id="índice-completo-de-routers"></a>
## Complete Router Index

For a broader categorized list see `ROUTERS_INDEX.md`.

<a id="ejemplos-representativos"></a>
## Representative Examples

| Domain | Endpoint | Description |
|---------|----------|-------------|
| Topology | POST /api/topology/report | Integrated report (diagrams, invariants) |
| Calculus | POST /calculus/partial-derivative | Multivariable partial derivatives |
| PDE | POST /pde/heat-1d | Heat equation simulation |
| Plausibility | POST /api/plausibility/evaluate | Evaluate scientific hypothesis |
| Scheduler | POST /api/scheduler/jobs | Create scientific job |
| Reproducibility | POST /api/reproducibility/package | FAIR reproducible package |
| Workflows | POST /api/workflows/execute | Execute scientific workflow |
| Conjectures | POST /api/number-theory/conjectures/generate | Generate conjectures |

<a id="autenticación"></a>
## Authentication

All critical endpoints require JWT (Authorization: Bearer `TOKEN`). See `auth.py`.

<a id="versionado"></a>
## Versioning

- Prefixes `/api` for laboratory and scientific services
- Legacy mathematical router prefixes without `/api` will be aligned in future versions.

<a id="estados-especiales"></a>
## Special States

Some endpoints return messages for optimization not implemented in `llm_routing` and streaming pending in `agent2_bridge_service`.
