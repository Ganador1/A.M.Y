<a id="-arquitectura-del-sistema"></a>
## 🔧 System Architecture

<a id="-flujo-de-procesamiento"></a>
### 🏗️ **Processing Flow**
```
Input: Research Question + Domain
    ↓
ScientificHypothesisAgent (ATLAS)
    ↓ 
ImprovedHybridConfidenceFilter v2.1
    ├── ML Component (R² = 0.960)
    └── Anti-Pseudoscience Patterns (5 categories)
    ↓
Decision: APPROVE/REJECT + Confidence + Reasons
    ↓
EnhancedHypothesisWorkflow
    ├── Statistics & Monitoring  
    └── Batch Processing Support
```

<a id="-componentes-del-filtro"></a>
### 🛡️ **Filter Components**
1. **Machine Learning:** Gradient Boosting trained with 66,461 retracted papers
2. **Pattern Detection:** 25+ regex patterns in 5 pseudoscience categories
3. **Exponential Penalty:** Penalty for detected patterns
4. **Decision Engine:** Threshold 0.5 for APPROVE/REJECT
