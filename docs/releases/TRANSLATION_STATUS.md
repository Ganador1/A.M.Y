# English documentation status

The maintained release entry points are in English. [English manuals](../ENGLISH_MANUALS.md) now indexes 205 translated historical Atlas documents, with source and derivative hashes in docs/en/TRANSLATION_MANIFEST.json.

DeepSeek v4.1 Flash produced the translations using up to 10 concurrent requests. Automated checks preserved protected code, mathematical expressions, numeric tokens and link targets and checked heading structure. Selected biology and evaluation manuals were read for quality. This is machine-assisted translation with structural checks, not an expert line-by-line technical review of all 205 documents. Historical claims are not revalidated by translation.

Broken historical references are labeled as resources not included rather than presented as working links. Public derivatives remove personal identifiers; original evidence remains unchanged locally. Source comments, literal examples and original research records can retain their original language. The inventory is heuristic, so this is not a claim that every Spanish phrase in the repository has been translated.

The default mission's memory namespace remains explicit to preserve continuity with earlier missions. New installations should use config.release.yaml.
