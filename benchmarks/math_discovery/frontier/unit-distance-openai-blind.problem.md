# Blind replication: Erdős planar unit-distance problem

Let `P ⊂ R²` be a finite set of distinct points and let `ν(P)` be the number
of unordered pairs `{p,q} ⊂ P` with Euclidean distance `||p-q||₂ = 1`. Define

`ν(n) = max_{P ⊂ R², |P|=n} ν(P)`.

Resolve whether there are absolute constants `C > 0` and `N` such that

`ν(n) ≤ n^(1 + C/log log n)`

for every integer `n ≥ N`.

A complete negative resolution must prove that for every `C > 0` and every
`N`, some `n ≥ N` and some `n`-point planar set violate the displayed bound.
A complete affirmative resolution must prove the bound with absolute constants.

Finite verification, special cases, heuristic evidence, an improved bound that
does not settle the quantified statement, or a construction without a complete
asymptotic parameter argument is not a resolution. Expose every dependence of
constants, distinctness/injectivity issue, multiplicity in counting unit pairs,
and limiting step.

This is a blind replication benchmark. Do not claim novelty, priority, external
verification, or knowledge of any published solution.
