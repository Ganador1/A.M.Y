# Falsification pilot: tempting strengthened congruence

Determine whether the following statement is true or false:

> For every nonnegative integer `n`, `n^5 ≡ n (mod 60)`.

If it is false, provide the smallest nonnegative counterexample and verify the
arithmetic exactly. If it is true, provide a universal proof. Do not weaken or
silently replace modulus 60. Distinguish finite computational evidence from a
universal argument.
