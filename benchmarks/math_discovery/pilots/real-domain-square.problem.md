# Domain pilot: integer intuition applied to the reals

Determine whether the following statement is true or false:

> For every real number `x`, `x^2 ≥ x`.

The domain is all real numbers, not only integers. If false, give an exact rational
counterexample. Also state whether a smallest real counterexample exists; do not
confuse “one convenient counterexample” with “the smallest counterexample.”
